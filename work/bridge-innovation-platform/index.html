BRIDGE — Mumbai Biocluster

An innovation and industry collaboration platform I built for Mumbai Biocluster, connecting biotechnology researchers, startups and industry partners around real challenges — from open-challenge discovery to submission intake.

Role: SoloStatus: Built, pending deployment

  • React
  • TypeScript
  • Vite
  • Tailwind CSS
  • React Router
  • Google Forms

Problem

Innovators — researchers, startups, academic groups — and the industry partners who could work with them had no shared digital space in Mumbai Biocluster's biotechnology ecosystem: no way to discover real industry challenges, submit a solution, or connect with the organizations behind a problem statement. That coordination was happening ad hoc, outside any platform.

What I built

A six-page platform — Home, For Innovators, Open Challenges, How BRIDGE Works, About, Contact — on a component-based, configuration-driven React and TypeScript front end. Vite handles the build, Tailwind CSS with custom design tokens carries Mumbai Biocluster's BRIDGE branding (a teal-and-gold palette), and React Router ties the six pages together.

Key features

  • A data-driven Open Challenges directory, typed with TypeScript interfaces (title, description, category, timeline, organization, status), so it can move to a real API later without a UI rebuild
  • Innovation and industry-challenge submission intake through integrated Google Forms, rather than duplicating a form-processing workflow the organization already relies on
  • Reusable navigation, footer, layout and challenge-card components for consistency and faster iteration
  • Centralized TypeScript configuration for form links, navigation and contact details, so routine updates don't touch page components
  • A custom, mobile-first responsive design system matching Mumbai Biocluster's BRIDGE branding

The hardest part

Deciding what not to build. Mumbai Biocluster already had a working intake process built around Google Forms; replacing it with a custom submission backend would have meant rebuilding and re-validating an evaluation workflow that already worked, for no real benefit yet. I integrated the existing forms instead and put the engineering effort where it was actually needed — the challenge directory's data model and the component architecture — so a future move to a real database or API doesn't require a UI rewrite.

Result

Delivered the initial front-end codebase: a six-page platform with a working Open Challenges directory, submission-form integrations, and a centralized configuration layer, ready for a production build and deploy.

See it

Not yet live — built and ready for deployment at bridge.mumbaibiocluster.org.
