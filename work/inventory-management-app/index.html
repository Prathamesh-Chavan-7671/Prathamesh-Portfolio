NRG LIMS

A full lab-lifecycle platform I built for the Nanomedicine Research Group: inventory, procurement, purchase orders, vendor management, samples, safety incidents, instrument bookings, characterization, publications, thesis tracking, waste management, analytics, reporting and audit logs, behind one role-based system.

Role: SoloStatus: Internal platform, in active use

  • Next.js 16
  • React 19
  • TypeScript
  • Tailwind CSS
  • PostgreSQL + Prisma
  • Redis + BullMQ
  • AWS S3
  • Docker

Problem

The research group needed one system to run the full lab lifecycle — inventory, procurement and purchase approvals, sample and safety tracking, instrument bookings, and the records that back publications and thesis work — instead of that living across separate tools and spreadsheets.

What I built

NRG LIMS end-to-end: every core lab workflow is implemented and RBAC-enforced, with a separate dashboard per role (PI, lab manager, researcher, student). It's built on Next.js 16 (App Router), React 19 and TypeScript, with PostgreSQL via Prisma for data, Redis and BullMQ for background jobs, AWS S3 for file storage, and runs on Docker Compose behind nginx on a self-hosted VPS.

Key features

  • Inventory, procurement and purchase orders — with a PI-approval gate and a three-quotation rule built into the workflow
  • Vendor management and product/purchase requests
  • Sample tracking and safety-incident logging
  • Instrument bookings and characterization records
  • Publication and thesis tracking, plus waste management
  • Role-based dashboards, analytics, reporting and a full audit log

The hardest part

Getting authorization right across the edge. Next.js's edge middleware (proxy.ts) can only cheaply check that a session cookie exists before a page renders — it can't afford to check roles and permissions there. So the real access-control decision stays server-side, re-checked on every action through a session guard, rather than trusting the fast edge check. That keeps pages quick to load without weakening who can actually do what.

Result

In active internal use by the research group, with every core workflow implemented end-to-end — inventory, procurement, requests, samples, safety, instruments, publications, thesis tracking, waste, analytics and reporting — under role-based access control.
